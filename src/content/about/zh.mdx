一名工作了十多年的资深软件工程师,目前在Red Hat 担任 Principal Engineer。过去十余年里,我一直在Red Hat,做着面向全球企业客户的产品。

## 我在做什么

最近几年的重心在两个方向:

一是 **AI Agent 与大模型工程化**。我正在带几个基于 LLM 的项目,围绕 MCP Server、Google ADK、vLLM 这些技术栈,把企业内部的安全知识、漏洞数据、合规信息变成大模型可以直接调用的工具。

二是 **面向企业客户的 Web 产品**。从客户门户的工具集、产品合规门户,到内核代码浏览器,这些产品的共同点是:用户是真实的企业客户,每一个 bug、每一次延迟,都会被使用它的人感知到。这种"离用户很近"的感觉,是我喜欢的工作方式。

## 我的技术栈

- **前端**:React / Next.js / Astro / TypeScript,做过 50+ 应用从 AngularJS 到 React 的整体迁移
- **后端**:Node.js (NestJS / Fastify) 为主,也写 Python、Java、Perl
- **云原生**:Kubernetes / OpenShift / Docker,CI/CD 流水线全套自己搭
- **AI**:MCP Server、Google ADK、LangGraph
